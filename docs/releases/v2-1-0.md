upgrade:
  head:
    eyebrow: UPGRADE
    heading: UPDATE IN ONE STEP.
    sub: Use Check now in the app's Settings, or run yerd update. Both the desktop app and headless installs update in place.
  notesTitle: Worth knowing before you upgrade
  notes:
    - Parked folders named after a domain get shorter names on first start (laravel-com.test becomes laravel.test). Favourites, groups, share settings and per-site services move with them, but update bookmarks and your app's APP_URL.
    - cloudflared moves into Tooling. An existing install is migrated automatically and your tunnel logins are untouched. Use yerd install tool cloudflared from now on.
    - On macOS, if you had elevated ports or LAN access, run sudo yerd elevate ports (and sudo yerd elevate lan) once to switch from pf to launchd. Until you do, the Doctor shows a warning.
  terminal:
    title: terminal
    lines:
      - '$ yerd update'
      - '$ sudo yerd elevate ports  # macOS, once, if you had elevated'
      - '$ yerd doctor'
